# Star Studio

<img src="plugin/icon@2x.png" width="72" alt="Star Studio 图标">

**在 Photoshop 中完成星空堆栈、星点分离与星点加工，用图层混合查看星点和背景的效果。照片在你的电脑上处理。**

[下载安装包](https://github.com/zjy6789/StarStudio/releases) · [报告问题](https://github.com/zjy6789/StarStudio/issues) · [第三方来源与许可](THIRD_PARTY.md)

Star Studio is a local astrophotography plugin for Adobe Photoshop on Windows. The installer includes Python and image-processing dependencies. Star removal requires a separate StarNet++ CLI installation; see the instructions below. Star-processing controls, previews and layer output have been checked in Photoshop 2026; see [validation status](VALIDATION.md).

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，x64。当前没有 macOS / Windows ARM 原生安装包。 |
| Photoshop | **2024（25.0）或更新版本**，使用 UXP Imaging API；历史原生验证环境为 Photoshop 2026（27.1），其他版本尚未逐个验证。 |
| 安装组件 | 已安装 Adobe Creative Cloud 桌面应用，且至少启动过一次 Photoshop。 |
| 内存与磁盘 | 建议 16 GB 内存；全尺寸大批量 RAW 建议 32 GB 及 SSD。缓存需求随分辨率和堆栈模式变化。 |
| 相机 RAW | 由捆绑的 LibRaw 支持；DNG 在 Photoshop 中的打开方式由 Camera Raw 决定。 |

无需安装 Python 或 CUDA，即可使用堆栈、曲线、星点缩小、辉光、饱和度和图层混合预览。**星点分离需要另装 StarNet++ CLI；彗差减少需要另装 Siril 1.4.x**。两个外部引擎独立配置，不影响其余功能。

## 线性堆栈仍很暗时（开发功能）

1. 保留原母版，进入 **线性提亮 → 选择线性TIFF…**，选择Star Studio原导出的32位线性ProPhoto TIFF。此路径保留零点和完整浮点范围；也可继续显式使用原样T4准备副本或“使用刚准备副本”。
2. 确认所选文件仍未拉伸，点击“读取并建议参数”。核对来源与范围提示；这一步只建立快照和建议，不会自动修改照片或应用曲线。
3. 点击 **仅查看提亮**，在PS临时标签页完整分辨率查看。调整提亮程度、亮星保护和背景亮度；可比较原线性输入，所有调整从同一磁盘快照重算。PS尚未保存的编辑不带入。
4. 检查实际范围和舍入反馈后，点击 **保存并应用拉伸…**。另存32位TIFF；PS结果层/原输入及撤销沿用原路径，新完整范围入口的原生显示和写回待用户手动验证。零强度仍标记线性。

只支持上述明确来源的线性ProPhoto RGB float32 TIFF，不自动重拉已显影照片或拉伸输出。原母版路径使用RGB绝对峰值的共同正增益，不裁切负值或超1高光；非零变零时停止。**完整范围输出若仍含负值或超1，不能直接用于现有0..1去星和背景工具。** 原T4路径依旧拒绝新增黑白端点。两条路径都有float32舍入，原母版不能删除；保色是明确空间下的比例约定，不是无损或自动颜色校准。[新路径与验证](docs/ZERO_PRESERVING_STRETCH.md) · [原T6约定](docs/PROTECTED_STRETCH.md)

## 已有单张FITS堆栈时（开发功能）

1. 在 **母版准备 → 导入一张FITS堆栈** 选择文件；灰度可以直接检查，三平面RGB须先确认来源软件使用的线性ProPhoto或线性sRGB空间，再点击 **检查数据**。
2. 核对范围与舍入报告，确认尚未拉伸；发生float32舍入时需另行接受。不能确认颜色空间、相机原生RGB或未去拜耳素材，请先在来源天文软件中处理。
3. 保存独立32位线性TIFF，可选择保存后打开。原FITS保留，负值和超1高光不裁切；灰度复制为中性RGB。此步没有拉伸或范围映射。
4. 需要本插件提亮时，可在 **线性提亮 → 选择线性TIFF…** 选择刚保存的32位母版以保留零点；原“使用刚保存的32位母版”范围准备路径继续保留。不要删除原FITS或把交接副本误认为已显影照片。

只支持一幅灰度或三平面RGB，不做FITS序列管理。遇到空值、压缩或其他布局会解释原因；不会自动填零、旋转或裁剪。头卡片、来源哈希归档到TIFF描述，WCS仅存档。[数据与验证边界](docs/FITS_IMPORT.md)

## 保护星点或主体时（开发功能）

1. 在 **星点加工 → 保护蒙版** 展开工具。星点覆盖使用上方已选择的原星点层；外来图层先手动确认分离关系。主体模式则使用源照片中手工建立的选区，点击 **读取主体选区**；无需先去星。
2. 生成覆盖预览，调整星点阈值、扩展与外柔化。白色代表覆盖区域；“星点外区域”仍可能含星云、地景和残留，不能当自动天空识别。
3. 检查范围，并明确是否 **保护白区（反选）**，勾选确认后应用。只更新来源文档选区，不改写图层像素；可用 PS 快速蒙版继续编辑。参数或来源变化后需要重新生成。
4. 也可保存完整尺寸 **32位灰度 TIFF**，供后续作为蒙版使用。导出白区与覆盖预览一致；反选只影响应用。已有文件不会被覆盖。

主体参数重算使用已读取的稳定选区快照；要更换主体需再次读取。本功能无新增必装引擎，计算和文件验证见 [保护蒙版约定](docs/PROTECTION_MASKS.md)；PS选区精度、撤销与面板操作仍待用户手动验证。

## 去星后需要检查残留时（开发功能）

1. 在源照片中选中可疑星点区域，到 **星点加工 → 去星残留局部检查** 手动选择分离前原图；如果保留了同次分离且未经后续编辑的模型背景，可另选该参考层。
2. 确认角色，点击 **创建局部比较副本**。它捕获当前可见合成，在同一32位PS文档中按原图像素切换原图、模型参考与当前合成；没有模型时明确只比较两项。
3. 需要手动修补时，点击 **创建全尺寸局部修补副本**，使用保留下来的精确选区及PS局部工具。原文档、旧比较和原始图层保留。

原图/模型首版限顶层、非剪贴、正常混合、100%不透明度/填充的像素或智能对象。比较只观察选区外接矩形，不把矩形当修补蒙版；不会自动提亮、归一化、再次去星或调用蒙尘划痕。原生裁剪、ICC、像素及选择精度待用户手动验证。[使用约定](docs/RESIDUAL_COMPARE.md)

## 怀疑亮星周围有蓝紫晕时（开发功能）

1. 在 **星点加工** 选择已确认分离关系的RGB星点层，打开 **蒙版与色晕候选**，选择 **蓝紫晕候选**。灰度不能判断颜色。
2. 调整紧致亮星检测下限、核心保护与外圈半径；色差门槛控制覆盖权重。生成并检查白区，确认它没有包含真实蓝星、星云或地景。
3. 确认覆盖后，选择 **应用选区** 或保存32位灰度蒙版，在Photoshop中继续编辑范围，并用色相/饱和度、选择性色彩或蒙版强度局部调整。

本功能只辅助选区，照片像素不变；没有候选时会停止，避免空选区造成误操作。它不判断真实光学成因，不自动压紫、模糊、修补或再次去星。半径单位是原图像素，必须按实际星点检查。[方法与边界](docs/HALO_MASKS.md)

## 天空偏色或希望增强银河颜色时（开发功能）

1. 确认照片已显影，在 **背景校正** 选择RGB照片或无星背景图层，展开 **天空校色与主体颜色**；无需先执行渐变校正。
2. 在源照片中选择可靠、平稳的天空，点击 **用此处作为天空背景**。可再选择需要排除的地景、星点或主体，点击 **选区保护主体**；两个选区分别保留快照。
3. 点击 **读取并生成颜色预览**。效果默认关闭；按需启用天空偏色修正或主体颜色增强，再更新预览。可比较原输入与作用范围。颜色增强保护暗背景与高亮，较暗星点可使用保护蒙版页生成的选区加以保护。
4. 检查颜色、取样和当前范围后确认，创建独立32位副本。原输入保留在效果层下方，可调效果层不透明度降低强度；原用户文档不改写。

这属于视觉校色，不是白平衡或测光标定；暖色天空、极光与地景灯光可能有意保留，不能一律变灰。结果保留负值/HDR并报告范围，不硬裁切。灰度和未准备线性母版不自动进入此流程。[算法、数据边界与验证](docs/SKY_COLOR.md)

## 背景色噪较明显时（开发功能）

1. 在 **背景校正** 选择已显影图层，展开 **背景降噪**。默认只处理选区：在源照片选中可靠背景后，点击 **读取背景作用选区**；也可用保护蒙版的星点外选区。确认整层无星且适合处理时，才选择整层范围。
2. 点击 **读取并生成降噪预览**，检查绿色参考块是否避开星云、地景和纹理。调整强度与细节保护，比较同一输入的原图和结果；改变强度复用降噪修正，不重复滤波。
3. RGB默认仅色噪，保留工作RGB亮度；灰度使用亮度降噪。高级联合模式会改变亮度并可能削弱暗弱结构。若高频估计过于保守，只有确认参考块为平稳背景后，才开启相关噪声选项；低频变化也可能是真实结构。
4. 检查后勾选确认，创建独立32位副本，保留原输入与可调效果层。原用户文档、alpha和ICC不改写，不整体缩放或裁切浮点范围。

这是内建NLM，不需要另装AI模型。它不修复去星彩圈，不承诺所有照片细节无损；没有干净真值的实拍诊断不能当成信噪比证明。本路径只验证已显影工作图像，不代表其他降噪也必须在拉伸后进行。[选型、数值边界与验证](docs/BACKGROUND_DENOISE.md)

## 背景渐变不均时

1. 在 Photoshop 打开已显影照片，在“照片阶段”确认后，进入 **背景校正**，选择照片或无星背景图层，点击“生成背景建议并预览”。无需先去星。
2. 检查面板绿点是否落在可靠背景。PS 新标签页提供完整尺寸的校正结果、拟合背景模型和原输入比较；模型包含保留的背景基线，实际只减去起伏。
3. 如果取样碰到银河、星云或地景，回到源照片，用套索或快速蒙版涂出主体，展开“主体保护与取样”，点击“选区保护主体”再生成。也可用分散的天空选区限定背景。保护只排除拟合，主体仍会接受同一梯度校正。
4. 调整强度（0恢复输入），检查后勾选确认，点击“创建背景校正副本”。结果在独立 **32位** 文档中保留原输入和新校正层，原文档不动；一次撤销本次输出可恢复副本原输入。

只估计大尺度一阶平面，不自动判断整幅星云的真实背景。取样不足或集中时应修改选区或跳过。透明边缘不参与拟合；未包含在alpha中的低覆盖边缘需手动排除。32位副本保留负值与超1高光，显示可能与原8/16位不同，比较以副本原输入为准。本页暂不处理未准备线性HDR，不代替平场、降噪或科学颜色校准。[完整约定](docs/BACKGROUND_GRADIENT.md)

## 安装与更新

1. 从 [Releases](https://github.com/zjy6789/StarStudio/releases) 下载 `StarStudio-版本-Windows-x64-Setup.exe`。Beta 请选择标有 **Pre-release** 的条目；“Source code” 压缩包是源码，不是安装包。
2. 双击安装程序。它将处理组件和面板放到 `%LOCALAPPDATA%\StarStudio`，生成本机专属配置，并调用 Adobe 安装工具安装面板。写入本项目目录不需要管理员权限；Adobe 的安装策略可能另外要求确认或提权。
3. 在 Photoshop 打开 **增效工具 → Star Studio → Star Studio**（英文：Plugins → Star Studio）。若新面板尚未出现，保存工作后重新打开 Photoshop。
4. 首次使用时允许插件启动本机处理组件。之后从 Photoshop 打开面板即可，无需运行 CMD 或保持服务窗口。

安装程序目前没有代码签名；请从本仓库 Release 下载，并可用 `SHA256SUMS.txt` 核对内容。Windows 或 Adobe 可能显示外部插件安装确认；安装程序不会绕过它们。[Adobe CCX 安装说明](https://developer.adobe.com/uxp/guides/how-to/distribution/install/)

**更新：**关闭 Star Studio 面板并等待至少 90 秒，让空闲组件退出，再运行新版安装程序。本机令牌保留；工作期间不要更新正在使用的组件。

**卸载：**在 Creative Cloud → 插件管理中卸载 Star Studio。关闭面板、等待后台退出后，可删除 `%LOCALAPPDATA%\StarStudio`，一并清除临时缓存与日志；不影响另存到其他目录的照片。项目不设置开机自启、登录自启或系统服务。

**安装失败：**查看 `%LOCALAPPDATA%\StarStudio\artifacts\install.log`，确认 Creative Cloud 已安装且 Photoshop 满足版本要求；也可双击安装目录内自动生成的 `StarStudio.ccx`，通过 Creative Cloud 重试。单独分享这份 CCX 无法为另一台电脑提供完整运行环境，请分享 Release 的 EXE。

### 安装 StarNet++ 星点分离引擎

StarNet++ 只需配置一次。它是外部程序，本项目不随包分发；无需把原始照片交给 StarNet 的界面打开。

1. 打开 [StarNet 官方 CLI 下载页](https://starnetastro.com/cli-tools/starnet/)，下载 Windows x64 的完整 ZIP。截至 2026-10-10 为 **StarNet2 2.6.2-0242 ORT**，可用页面提供的 SHA-256 校验。
2. 将 ZIP **完整解压**到固定的英文路径，例如 `D:\AstroTools\StarNet2`。当前新版的模型加载不兼容中文引擎路径；Star Studio 项目和照片目录仍可使用中文。保留 `starnet2.exe`、`StarNet2_weights.onnx`、`LICENSE.txt` 和所有 DLL 的相对位置；不要只复制 EXE，也不要混用不同发行包的 DLL。
3. 打开 Star Studio 的 **星点分离 → 星点提取模型：StarNet**，点击“选择程序…”选中 `starnet2.exe`，也可在唯一的“StarNet 程序位置”输入框填写完整路径，不加引号。开发版另有“查找已安装”，仅查已知目录，优先保留当前可用路径；首次没有保存路径时可预填通过文件检查的候选。状态会提示缺程序、模型或许可文件；文件齐全不代表已验证运行库或GPU。点击“查看当前引擎许可”，阅读完整条款并明确勾选同意；发现候选不会自动接受许可。同一条款只需接受一次，条款改变需重新接受。路径与许可选择自动保存。[首次使用边界](docs/FIRST_USE.md)
4. 保持处理步长为 **256**，选择 Photoshop 中的源图层，点击 **执行星点分离**。插件自动调用引擎并创建两个结果图层。官方 Windows 包自带 DirectML，可使用兼容 NVIDIA / AMD / Intel GPU；不可用时自动回退 CPU，无需另装 CUDA 或 cuDNN。实际执行设备见任务缓存目录中的 `starnet.log`，不是仅依据显卡型号判断。

**选择 CPU 版：**可在 [官方旧版 CLI 下载页](https://starnetastro.com/cli-tools/legacy/)下载 `StarNetv2CLI_Win.zip`，完整解压到另一个目录，在同一个“StarNet 程序位置”选择 `starnet++.exe` 即可。插件自动使用旧接口；已为 Siril 配置的同版目录可以复用。它使用旧版 v2.0.2 模型/运行库，处理效果可能与新版不同。新版 2.6.2 CLI 没有公开强制选择 CPU 的参数，自带的 CPU 回退仍可用。

更新时先保留可用目录，再从官方源下载完整发行包并切换路径；不要覆盖仍在使用的引擎。若提示“找不到 StarNet”或权重加载失败，检查 EXE 路径、完整解压目录及发行包 README。新版最低尺寸为 512 × 512，插件对较小图层反射补边，完成后还原原尺寸。Star Studio 仍只处理 `0..1` 普通范围像素，不会自动裁掉堆栈的超范围高光。

**独立官方 PS 面板：**可从 [StarNet2 Photoshop 下载页](https://starnetastro.com/ps-plugins/starnet/)下载 CCX，通过 Creative Cloud 安装；目前为 **1.0.4-0005**，要求 Photoshop **26.11.7 或更新**。从 **增效工具 → StarNet2 → StarNet2** 打开，与 Star Studio 独立共存、自带模型，无需 CLI 路径。官方面板支持已拉伸的 8/16 位 RGB/灰度，暂不支持线性或 32 位图片；比较效果时应使用同一图片和参数。[官方安装说明](https://starnetastro.com/ps-plugins/installation/)

## 从堆栈到星点加工

从线性素材开始可按 **堆栈 → 母版准备 → 线性提亮 → 按需背景校正 / 星点分离 → 星点加工** 继续；已有显影照片可以跳过堆栈、准备和初始提亮。各处理均可按目标跳过。图层自动同步，星点和预览背景都由用户自己选择。星点加工通过 Photoshop 原生图层混合展示合成效果，不再提供独立的星点重混合页面。

### 1. 堆栈

在面板选择多张照片或文件夹；输入素材无需预先在 Photoshop 打开。

- 基础目的选择 **普通降噪**（均值）或 **排除偶发亮线 / 异常像素**（Sigma裁剪均值）。Sigma也可能排除希望保留的流星；效果依赖帧数和内容，少量素材优先均值，不按一个通用张数门槛替你决定。
- **高级模式与格式** 保留均值、中位数、Sigma裁剪均值、最大值、最小值。展开/收起不改变选择；高级模式在基础区域明确显示，不伪装成普通降噪。最大值仍先对齐星点，不是星轨合成。
- 素材按自然文件名排序，以排序后的中间一张为基准。纯星空直接配准；带地景模式排除检测到的跨帧固定特征，只对齐星空。
- 固定地景检测不是语义分割。可用画笔涂抹山脊、灯光等区域，排除其参与星点匹配。蒙版不删除像素；地景随天空变换，允许拖影。
- 在 **堆栈后下一步** 选择Camera Raw显影（默认32位线性DNG）、插件继续处理（32位线性TIFF母版，尚未拉伸）或Siril/天文软件（32位FITS）。16位格式仍可高级手选，量化/截断说明始终显示；更换素材不会重置你的明确选择。完成后只在Photoshop打开结果，原素材不打开、不改写。[选择与验证边界](docs/STACK_INTENT.md)
- 展开 **校准场（可选）**，分别选择暗场、平场、偏置场的多张文件或文件夹，可任意清除；较长曝光平场可增加匹配的平暗场。全部不选时使用原有流程。暗场可以单独使用；平场先去偏置或匹配平暗场，未提供时 Bayer RAW 使用自带黑电平近似。暗场不自动缩放，需匹配曝光、ISO/增益与温度。[组合与拍摄要求](docs/CALIBRATION.md#可选组合与依赖)

| 输出格式 | 信息与用途 |
| --- | --- |
| **DNG**（默认） | 32 位浮点 **LinearRaw DNG**，保存去马赛克后的相机线性 RGB、色彩矩阵及白平衡；不是原 CFA RAW 的无损替代。Camera Raw 可能以 16 位文档打开。 |
| **32 位浮点 TIFF** | 带线性 ProPhoto RGB ICC，保留负值及超过 1 的高光；适合直接在 Photoshop 中保留 32 位处理空间。 |
| **16 位 TIFF** | 最后一次量化，负值截零；必要时全图统一缩放以保留高光比例。缩放、截断和配准信息写入同名 JSON。 |
| **32 位 FITS** | 线性 RGB 浮点三平面，保留负值与高光；颜色与校准元数据在 FITS 扩展中。Photoshop 通过临时 32 位 TIFF 打开结果。 |
| **16 位 FITS** | 缩放整数，以 BSCALE/BZERO 保存完整正负值范围，仍有量化；Photoshop 通过量化前结果生成的临时 32 位 TIFF 打开。 |

请保留原片。未使用校准场的 RAW 沿用线性 AHD 去马赛克与 16 位解码后转浮点的路径。使用校准场的 Bayer RAW 在未去马赛克的 float32 传感器平面，复用 ccdproc 完成校准，再用开源 Colour Malvar 算法做浮点去马赛克，保留负值和超范围高光；均值仍以 float64 累加。不自动提亮、不逐帧白平衡或曝光归一化，不做 8 位往返或显示拉伸。去马赛克、重采样与有限精度计算仍有边界，不能宣称全过程无损。当前堆栈页面不提供自动显示拉伸或 HDR 准备。

校准支持原始 RGB Bayer RAW，以及明确声明已线性显影、去黑电平的 16/32 位 TIFF；不接受 JPEG/PNG、非线性 TIFF、已去马赛克的 DNG 或 X-Trans 作为校准输入。主校准场一次合成、浮点分块与磁盘缓存，记录来源及参数，不修改输入素材。FITS 保存后只打开临时 TIFF 结果，后续 Photoshop 编辑请另存 PSD/TIFF；不需要在 Photoshop 打开亮场或校准场原片。

均值/最大/最小逐帧累积；中间值与 Sigma 使用磁盘缓存、分块统计。**100 张 2400 万像素 RGB 浮点帧仅对齐帧缓存约 26.8 GiB**，另需工作空间和输出文件。小图预览速度不能代表全尺寸 RAW 速度。

无 ICC 的 TIFF 假定为线性 ProPhoto RGB；JPEG/PNG 无 ICC 时按 sRGB 解码。暂不支持 LUT ICC、透明堆栈素材、不同尺寸或不同相机混合。详细精度与色彩约定见 [处理说明](docs/PROCESSING.md)。

### 2. 母版准备（线性TIFF，可选）

已在 Photoshop 打开显影照片的用户可以跳过此页。它用于 **Star Studio 导出的未拉伸32位线性ProPhoto RGB TIFF母版**；首版不自动准备DNG、FITS、灰度、透明通道或外来ICC照片。需要此流程时，在堆栈保存格式中选择32位TIFF。

1. 选择母版文件，或显式点击“使用刚保存的32位母版”。插件检查原始范围、ICC、负值和超范围高光；无须先把母版打开到PS。
2. 确认这是尚未拉伸的母版。位深和ICC不代表照片从未被编辑，软件不会擅自猜测。
3. 点击“创建后期副本并打开…”，选择新的TIFF位置。副本保持32位浮点、原尺寸和线性ProPhoto配置，原母版文件不变。检查与执行之间修改了母版时，需要重新检查。

全图RGB共享同一范围映射，不按通道或百分位裁切，不把NaN/Inf填成黑色。原始范围、offset/scale及实际浮点舍入误差写入TIFF描述，并在面板显示。负值需要共同抬升零点，可能改变颜色比例；极端动态范围在float32副本中也可能损失低位差异，**副本不能替代母版，也不称为无损或保色显影**。本版不自动裁剪或接收含NaN/Inf边界的母版，需选择完全有限的有效母版。

实拍补验中，一组全尺寸母版的零点抬升明显使画面趋灰；后续提亮不能恢复此前颜色比例。0.24开发中可直接选择原线性TIFF提亮以保留零点，文件结果已核对，PS显示/写回仍待手动验证；它不会自动修复已有T4副本。请保留母版比较显影结果，原有DNG→Camera Raw路径仍可使用。[原路径观测](docs/REAL_WORKFLOW_VALIDATION.md) · [保留零点入口与限制](docs/ZERO_PRESERVING_STRETCH.md)

**范围准备没有进行非线性拉伸，也没有额外显示提亮。** 副本仍可能很暗，当前会话仍将其标为线性；请继续在独立副本显影，确认“已显影照片”后再去星。它不会反复准备已带本插件标记的副本，也不会放松普通图层上传的0..1检查。[数据约定与支持边界](docs/LINEAR_PREPARATION.md)

### 3. 星点分离

在 Photoshop 中打开照片，选择来源图层，点击 **执行星点分离**。

0.7候选中可先点击顶部 **处理当前照片**，并在“照片阶段”确认已显影；线性母版请先保留原文件，在副本中完成显影。分离成功后，点击 **使用刚分离的星点与背景** 才会带入加工，不会自动覆盖手动选择。也可点击 **查看无星背景**，以可撤销的副本查看；0.6安装包仍按原页签手动选层。

- 生成 `XXX_starless` 背景和 `XXX_starmask` 星点图层，保留原始 `XXX`。星点图层初始隐藏，便于直接查看背景。
- 首次使用前按上面的 [StarNet 安装步骤](#安装-starnet-星点分离引擎)配置 CLI 位置及许可；之后直接执行。
- 支持滤色和相加分离；在星点加工中选择对应的滤色或线性减淡（添加）混合模式，可查看还原效果。
- 0.7候选的32位分离固定使用相加差值，匹配可用的线性减淡（添加）；不通过降低位深启用滤色。
- 如果星点周围出现明显彩色暗圈，可勾选 **保留模型背景（减少彩色残留）**，然后重新执行分离。默认关闭，不追加模糊或第二次去星推理；它保留模型填回的背景，并将正负差值保存到星点层。模型本身的残留仍可能存在。
- 勾选后，8/16 位星点层使用灰底编码并自动设为 **线性光**；32 位使用浮点差值和 **线性减淡（添加）**。灰底层请保留线性光模式，星点加工会自动识别、解码并只调整正星点信号，负修正保留。建议使用16/32位：灰底整数编码仍有量化，不能称为无损。详细对照与精度见[彩色残留调查](docs/STAR_REMOVAL_ARTIFACTS.md)。
- 模型可能改变星云、星晕或地景细节；请放大检查，必要时用原图局部修正。
- 默认步长256；在「星点提取模型」中，新版可选384，适合广域小星点。128/64会明显增加计算量。步长会改变去星效果，不等同于纯性能开关；选择建议见[官方文档](https://starnetastro.com/documentation/starnet/tips-and-tricks/)。
- 新版推理显示实际 GPU/CPU 后端与进度；完成后列出读取、引擎和写回时间，释放临时像素缓存。分离始终使用完整尺寸，新版用 float32 FITS 中转。

图层操作支持 RGB / 灰度、8 / 16 / 32 位普通范围像素。32 位 HDR 若超出 `0..1` 会报错，须先映射到普通范围；这与允许超范围高光的 RAW 堆栈流程不同。新图层保持文档尺寸、颜色配置与透明度；智能对象输出为新的像素图层。

### 4. 星点加工

手动选择星点图层，可再选择同一源文档中的背景图层。选择星点后自动在 Photoshop 新标签页打开全分辨率预览，无需点击预览按钮；选择背景后，可边调整星点边查看它覆盖背景的效果。

当前开发版可显式 **使用刚分离的结果**。本会话关联按图层ID记录，重命名不会丢失；删除或换文档后不会按相似名称猜测。基础页面显示当前是否与分离关系匹配，**恢复匹配混合** 使用已记录或手动确认的关系；外来星点请展开 **高级混合与分离关系** 确认，也可在其中自定义混合模式。收起后仍显示自定义状态，不改变所选模式。灰底修正和32位负差值必须保留其编码，不能只因名字带 starmask 就当作黑底图层。[分层边界](docs/MATCHED_BLEND.md)

混合模式使用 Photoshop 原生的 **正常、变亮、滤色、颜色减淡、线性减淡（添加）、浅色**。可用模式以当前文档位深和 Photoshop 支持为准；不会为了使用某种模式自动降低文档位深。滤色分离通常搭配滤色，相加分离搭配线性减淡（添加）；其他模式适合按需要调整外观。

点击功能展开常用控制，高级参数可另行展开；展开不会启用效果，勾选后才参与加工。“自然控星”只启用温和缩星，“柔和亮星”只启用辉光；预设会替换当前加工设置，面板显示启用项与实际半径。半径单位是原图像素，预设只是起点，请在100%视图按星点大小调整，不会按照片总像素数猜测最佳半径。“重置参数”关闭全部加工，恢复原效果。

完成后执行星点加工，在源文档创建新的 `_processed` 星点图层，并自动设置为预览时选定的混合模式。0.7候选选择背景时，另外复制背景并输出独立合成组，星点和背景仍是两层；未选背景只输出星点。原输入与本会话关联的旧结果保留在不透明度为0的分组中，避免重复叠星，并可一次撤销恢复结构和上一结果。原层像素和自身属性保留；其他未选图层仍保留，透明区域会透出下方内容。0.6安装包仍只生成星点层，需要自行管理原星点可见性。

| 功能 | 参数与用途 |
| --- | --- |
| 星点亮度 | 先调EV；高级选项保留阴影、中间调、高光锚点 |
| 缩星 | 先调强度；高级保留原图像素半径、暗星阈值与亮星保护 |
| 拉长星点修整 | 默认关闭；Siril 星点检测与圆星重建，高级保留形状阈值；需要 Siril 1.4.x |
| 辉光 | 默认关闭；先调强度与大小，高级保留亮度范围、过渡和外晕 |
| 星点颜色 | 先调饱和度，高级保留高光保护起点 |

预览保持源文档的完整像素尺寸，可使用 Photoshop 的缩放和移动观察细节。预览打开时仍可切换背景、星点、混合模式和加工参数；打开预览标签页不会把它当作新的输入文档。背景与混合模式切换由 Photoshop 直接更新，不重新计算星点效果；图层读取和加工结果会缓存，连续拖动参数时以最新设置为准。

选择背景时可勾选“查看原合成”，在同一预览文档、同一背景和混合模式下比较加工前后；未选背景时是“查看原星点”。比较只改变显示，执行仍使用当前加工参数。预览标题包含源照片名；参数尚在计算或更新失败时，面板会说明当前仍显示原合成或上次完成结果。

全分辨率预览不会降采样。首次读取大图、辉光和彗差减少等计算仍可能需要等待，耗时取决于照片尺寸、参数和电脑配置；不能保证每次拖动都立即完成。彗差减少针对检测到的拉长星点做圆星重建，属于外观修整，不等同于恢复真实光学 PSF 或原始测光信息。

## 隐私与后台组件

照片不上传云端。组件仅监听 `127.0.0.1:8765`，安装时生成独立随机令牌；使用插件时按需启动，空闲且无任务时约 90 秒退出。不设置开机自启、登录自启或系统服务。

UXP 网络声明为 `domains: "all"`，用于兼容部分 Photoshop 对回环域名声明的限制；代码将图像请求限制为上述本机回环地址。发行包不含用户照片或预生成令牌。

临时像素、缓存与日志位于安装目录 `artifacts/`，不自动上传。组件退出后可清理，任务期间不要删除。反馈日志前请检查是否含不愿公开的文件路径。

## 从源码运行 / 构建

开发环境：Windows x64、Python **3.12**、Git；JavaScript 检查另需 Node.js。普通用户请使用 Release。

```powershell
git clone https://github.com/zjy6789/StarStudio.git
cd StarStudio
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe tools\install.py
```

最后一条生成本机配置、启动器和 CCX，并通过 Adobe UPIA 安装。也可生成配置后使用 UXP Developer Tool 加载 `plugin/manifest.json`。不要分享或提交含有本机令牌的 `plugin/bridge.json`。

构建可分享的独立安装包（不会安装到 Photoshop，也不会启动照片处理）：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.venv\Scripts\python.exe tools\build_release.py --tag v0.7.0-beta.1
```

输出在 `dist/`：Windows EXE、LGPL 对应源码归档与 SHA256 清单。构建会下载与捆绑库版本对应的第三方源码，安装及日常处理无需这些下载。项目完整源码和构建脚本由对应 Git 标签提供。

开发分支的首轮工作流迭代（T1）：顶部可选择“处理当前照片”或“从多张原片开始”，已有照片无需先堆栈。去星前在“照片阶段”确认已经显影；线性堆栈请保留母版，在副本完成显影后再处理。阶段不会按位深自动猜测，也不会替你拉伸或裁剪像素。已有星点层的加工不要求安装 StarNet。详见[迭代与回退记录](docs/ITERATION_T1_T2_2026-10-18.md)，本段不代表 GitHub 已发布安装包包含这些修改。

开发检查（不属于普通安装步骤）：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-test.txt
.venv\Scripts\python.exe -m pytest -q
node --test tests\test_star_processing.js tests\test_host_write.js tests\test_model_settings.js tests\test_star_canvas.js tests\test_extract.js tests\test_stack.js tests\test_panel_startup.js
```

`tools/` 的 smoke/native 脚本会实际处理图像，部分需要本地测试素材、Photoshop 或外部引擎；不要把它们作为安装步骤。持续集成不能代替 Photoshop 原生验证。
