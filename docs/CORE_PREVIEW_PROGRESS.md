# 加工页离开后的传输进度隔离

基线`c9873bc`，版本0.24.6，范围是T24已有页面隔离的遗漏，不增加功能、参数或引擎。

## 复现及修复

0.24.5已经保护加工任务的进度和状态文字，但完整图层上传、PS预览写回仍直接调用全局进度回调。离开加工页后，已开始的传输安全完成时可能覆盖其他页的进度条。

两个新增控制器回归先失败：上传晚到、预览写回晚到都在另一页报告了1。另在Photoshop27.1的256×1024 RGB16/sRGB图层上复现真实分块上传：第一块512行成功、后台仍未完整就绪时离页，将其他页进度置为测试哨兵0.37，传输完成后被改为1；没有注入图像或API结果。哨兵只用于观察串写，没有运行并发堆栈作业。本机记录`artifacts/native-progress-20261023/native-progress-before.json`。

只给上传与预览写回的进度回调增加当前页判断。继续安全完成已经开始的读取，保留输入和返回复用；直接执行会暂停自动预览，因此没有用暂停标记屏蔽合法执行进度。没有改变任何图像数组、PS像素调用、后台、依赖或算法。

## 验证安排

修复后上述两项通过，另加直接执行在自动预览暂停期间仍报告上传进度的对照，控制器共39项通过。完整Node回归、修复后原生复验、开发包及完整范围回退以随后补充的实际结果为准；不凭旧0.24.5原生大图结果宣称新页面行为已通过。本阶段不重复计算未改变的Python数值算法，既有证据见VALIDATION。
