# T7 参考地景分层约定

基线：`checkpoint/0.10.0-candidate-20261021`。本阶段实现调研报告F的第一阶段：天空对齐堆栈与未变换的中间参考帧，在PS作为两个图层输出，用户自行用蒙版融合。地景独立多帧堆栈、自动地平线融合另行实施。

## 数据与用户操作

- 在堆栈页提供默认关闭的“同时保留参考地景”选项；独立于纯星空/排除固定地景特征的配准设置。红色画笔仍只排除配准特征，不转换为最终融合蒙版。
- 默认中间帧取自现有自然排序。参考地景是这帧经过同一校准、去马赛克和色彩管线后的整张图；不随天空变换、不再次解码或插值，不宣称单帧获得堆栈降噪。原RAW和校准场保留。
- 保留DNG默认与五种保存格式。开启分层时，用户选择输出文件夹，插件在其中创建独立结果子目录；主文件仍按所选格式保存。另存全尺寸32位线性ProPhoto参考TIFF，以及需要时的天空32位TIFF，记录两层来源与校准信息。32位TIFF主文件可直接作为天空层来源，无需重复保存天空。
- PS打开的是同一颜色空间/位深、量化前的天空与参考TIFF；不分别通过Camera Raw显影两张DNG后假定颜色相同。DNG/FITS母版仍保留所选格式的数据约定。16位主文件有原有量化限制，不能把32位PS图层称作来自16位主文件的无损恢复。
- PS新文档保留完整天空结果为可见底层、参考地景为隐藏顶层（名字明确“单帧，未降噪”）。用户显示参考图层并添加蒙版；默认不让整张单帧遮住降噪天空。输入图层/其他用户文档不改、不关闭、不降低位深。提示下一步及另存PSD以保留图层。

## 保存、权限与性能

- 复用现有SEP/Astroalign/OpenCV配准和校准后的reference缓存，不另造配准算法。均值仍分块float64累积、结果float32；不新增归一化、裁黑、截高光或缩图。新功能只增加可选输出，关闭时走原堆栈路径。
- 使用UXP文件夹选择获得新结果目录与子文件的明确访问；不扩大全局文件权限。File.createFile仅建立条目，后台写入后可创建session token；实际行为仍需PS验证。[Adobe文件系统接口](https://github.com/adobedocs/uxp-photoshop/blob/main/src/pages/uxp-api/reference-js/modules/uxp/persistent-file-storage/storage.md)
- 分层文件先在目标磁盘同一任务临时目录写完，再提交到新结果目录，拒绝已有文件和任何来源路径/硬链接碰撞。Windows提交不覆盖现有目标；取消/失败回滚本任务新建文件，保留原文件和未知条目。JSON与图像保持同组来源，PS打开失败应明确说明已保存的位置。
- 不保存全部对齐帧来实现地景输出；复用已存在的reference内存映射。说明额外磁盘为一张参考TIFF，非32位TIFF主格式还需天空TIFF。不得拿小图耗时代表几十/上百RAW性能。

1. 合成移动星空/固定地景：天空结果保持原堆栈数值，参考帧与独立读取/校准结果一致，包含负值与超范围高光。五种保存格式均核对PS双层来源32位/ICC与记录，不以16位主文件验证替代浮点层验证。
2. 真实已授权银河地景RAW小组及暗/偏置校准：选择的是中间帧，参考地景未被天空插值，源哈希不变；记录实际时间和输入数，不推广到所有素材。
3. 真PS：尺寸、32位、ICC、层序/可见性、像素、无源素材打开、其他文档保留；文件夹取消、计算取消、保存失败和PS打开失败能恢复操作。正式鼠标操作与注入选择的原生测试区分记录。
