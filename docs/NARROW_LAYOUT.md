# T18：窄栏布局候选

从已推送的 `checkpoint/t17-code-verified-20261022`（9f50e42）建立 `codex/narrow-layout-t18-20261022`，补齐调研4.10的独立布局试验。当前仍声明最小660px；实际PS验证后才考虑降低声明，本阶段没有启用380px正式停靠，也没有访问PS前台。

## 变化范围

- 640px及以下的候选规则：六个页签排为两行；目的按钮逐项排列；长操作按钮可换行，程序路径和图层选择占独立行。
- 高级堆栈模式/格式与成对数值组上下排列；参数标签与其数值保持同一组，长标签允许增加行高；画笔开关与笔刷控件可换行。
- 长文件名、许可和技术状态保留局部横向滚动，不让长字符串撑大整个面板。校准行沿用已有换行，不重写。
- ID、事件、控制项和算法不变；660px及以上继续原布局。没有删功能或清理原有无关CSS。

按find-docs核对[Adobe宽度媒体查询](https://developer.adobe.com/photoshop/uxp/2021/uxp/reference-css/Media%20Queries/width/)、[flex-wrap](https://developer.adobe.com/photoshop/uxp/2021/uxp/reference-css/Styles/flex-wrap/)及[overflow-x](https://developer.adobe.com/photoshop/uxp/2022/uxp-api/reference-css/styles/overflow-x)。宽度查询自UXP4.1支持；多面板仅按首面板计算是已知限制，本插件当前仅一个面板入口。

## 离线证据与待办

使用独立配置的无头浏览器渲染本地静态副本，移除main.js，不调用插件业务代码或PS API。六页分别检查380/400/420px，共18种组合；有滚动条时有效内容宽度会少15px。Spectrum控件使用替身，星点加工标签来自实际参数定义，不能据此宣称真实控件已兼容。

在长中文标签、长路径、展开选项与参数卡片的此组样例中，候选未出现整页横向溢出、控件横向越界或按钮文字纵向截断；原堆栈样例有6个截断按钮，候选为0。660px堆栈控件几何与基线完全相等。完整Node261项通过；未修改科学计算，沿用T17的Python430项及冻结数值证据。本地静态截图与几何记录在 `artifacts/t18-20261022`，均明确标为浏览器原型，未当作PS截图。

原生待验证：380/400/420px实际停靠、Spectrum菜单与长图层名、中文/技术提示、滚动到底部、笔刷坐标、宽窄切换及660px原布局。须通过这些门槛才降低manifest最小宽度；当前开发安装包亦保持660px，不把候选当作正式窄栏功能交付。
