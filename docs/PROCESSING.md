# 图像处理、精度与工作流

## 星空堆栈

1. 切换「堆栈」，点击「选择照片…」多选文件，或「选择文件夹…」。文件夹只读取当前层级，至少两张。支持常见 RAW、DNG、TIFF、PNG、JPEG；RAW 与已显影图片须分开堆栈。
2. 按文件名自然排序，例如 2 在 10 之前；默认使用中间第 `N//2+1` 张作基准。0.12开发分支可用「基准帧」显式改选本组任一张；读取成功后才切换预览并清除旧画笔，失败时保持旧选择。面板显示顺序、基准文件名和预览，不把原素材打开到 Photoshop。
3. 选择均值、中间值、Sigma 剔除均值、最大值、最小值。普通降噪推荐均值；Sigma 模式可剔除离群像素。最大值、最小值主要用于特殊合成。
4. 对齐场景选择「纯星空」或「星空＋固定地景」。地景模式比较首、中、末帧的星点候选，排除固定灯光等特征，再对移动星点配准；它不是语义地景分割。星空移动过小、树影、云、极强地景或鱼眼畸变时，自动判断可能不足，宜配合画笔。
5. 勾选「画笔排除对齐区域」，在基准预览中涂抹地景或其他干扰区域；红色蒙版只排除配准特征，不删除图像像素。地景仍参与随天空变换后的堆栈，因此可能拖花。可调整笔刷大小、清除蒙版。
6. 选择保存格式，点击「执行堆栈并保存…」。完成后只打开堆栈结果；同名 JSON 保存输入顺序、基准、各帧对齐矩阵与误差、覆盖数量、色彩信息和编码缩放。

0.12开发分支可展开「配准与覆盖报告」查看逐帧匹配数和RMS。覆盖预览越亮，参与几何覆盖的帧越多；青框是全部帧共同覆盖的矩形建议，坐标右/下边界不包含。它不代表噪声质量或Sigma剔除后的样本数，不会自动裁剪或排除素材。可导出完整16位PNG，每个像素值就是覆盖帧数（例如值30代表30帧，并非照片亮度）；完整图也以 `quality.png` 的PNG data URL保存在同名JSON内。查看缩小预览不影响母版尺寸或像素。原生面板与导出选择框尚待用户手动验证，数据检查见 [STACK_QUALITY.md](STACK_QUALITY.md)。

可展开「校准场（可选）」选择暗场、平场、偏置场与匹配平场曝光的平暗场，支持文件夹或多选文件，全部不选时保持原有处理。校准组合、开源来源与精度边界见 [CALIBRATION.md](CALIBRATION.md)，已完成检查与剩余范围见 [验证记录](../VALIDATION.md)和[测试计划](CALIBRATION_TEST_PLAN.md)。

配准复用 MIT 开源 [Astroalign](https://github.com/quatrope/astroalign) 的三角星点匹配，使用 SEP 检测星点、OpenCV 精化投影变换及单次 Lanczos4 重采样。基准帧不重采样；边界按实际覆盖帧数计算，避免黑色填边降低亮度。无法可靠匹配的帧会明确报错，不静默跳过。

0.12开发分支在配准失败后显示具体失败文件及失败前的记录，不将其当作完成结果。可显式点击「排除失败帧并重新读取」后重试，「撤回全部排除」恢复本组文件；原文件不会删除，至少保留两张。未移除当前基准时保留原画笔；移除基准时采用剩余素材的中间帧并清除旧画笔。重新选择新文件组会重置排除，取消选择则保留当前组。原生选择操作仍待用户手动验证。

不使用校准场时，RAW 通过 LibRaw/rawpy 做线性 AHD 去马赛克，禁用自动白平衡、自动提亮和按帧调整白点；相机色彩矩阵、基准帧白平衡保留在 DNG 中。LibRaw 此接口输出 16 位线性通道，随后立即转为 32 位浮点；这一步仍有去马赛克、量化和传感器黑电平处理，并非逐比特保留全部原 RAW。使用校准场的 Bayer RAW 在 float32 传感器平面完成黑电平、偏置/暗场和平场处理，再做不截断的浮点 Malvar 去马赛克，不经过 16 位显影中转。后续不做显示拉伸、逐帧曝光归一化、8 位往返或正值高光裁剪。均值以 64 位浮点累加，结果为 32 位浮点。面板预览的拉伸只影响显示。

| 保存格式 | 信息与用途 |
| --- | --- |
| DNG（默认） | 32 位浮点 **LinearRaw DNG**，保存去马赛克后的相机线性 RGB、颜色矩阵和白平衡，保留负值及超过 1 的值；天空旋转后无法保留原 CFA 马赛克结构。不是原相机 RAW 的无损替代，原素材请继续保留。 |
| 32 位浮点 TIFF | 线性 ProPhoto RGB，嵌入 gamma 1 ICC；保留负值和超范围高光，便于 Photoshop 32 位处理。 |
| 16 位 TIFF | 同一线性色彩空间，最终一次量化；负值截为 0，超过 1 时对整张结果统一缩放以保留高光比例，缩放与截断数量写入 JSON。信息保留优先时选上面两项。 |
| 32 位 FITS | 线性浮点 RGB，保留负值与高光；颜色与校准信息写入 STARMETA 扩展及同名 JSON。通过插件临时 32 位 TIFF 在 Photoshop 打开。 |
| 16 位 FITS | 使用 BSCALE/BZERO 覆盖全部正负值范围，最终一次整数化并记录量化步长。Siril 1.4.2 读取此缩放会丢失浮点范围，Siril 工作流请选 32 位 FITS。Photoshop 临时 TIFF 来自量化前结果，后续编辑请另存。 |

带 RGB 矩阵/色调曲线 ICC 的 TIFF 按配置在线性空间处理；无 ICC 的 TIFF **假定为线性 ProPhoto RGB**，请优先选择带 ICC 的素材。PNG/JPEG 无 ICC 时按 sRGB 解码；它们已有的压缩、8 位精度和显影处理无法恢复。当前不支持 LUT ICC、透明素材、不同尺寸或不同相机混合；单组素材应保持曝光、ISO、焦距与相机设置一致。不同 RAW 相机格式的兼容性取决于安装的 LibRaw。

均值/最大值/最小值逐张解码与累积，内存不会随素材数量线性增长。中间值与 Sigma 模式将对齐帧缓存到项目磁盘，再分块统计，面板显示缓存估算；100 张 2400 万像素 RGB 浮点帧仅帧缓存约 26.8 GiB，还需结果与工作空间。可取消任务，临时缓存会清理。处理期间需要的磁盘与内存取决于分辨率、模式和 RAW 解码器；大批量通常均值最快。

DNG 文件与 PS 文档位深是两回事：本机 Camera Raw 默认将 DNG 打开为 16 位文档；HDR 工作流可打开为 32 位，参见 [Adobe HDR 文档](https://helpx.adobe.com/camera-raw/desktop/hdr-and-advanced-output/hdr-output.html)。要直接在 PS 保持 32 位浮点，请选择 32 位 TIFF。插件不修改 Camera Raw 的全局设置。

此前开发验证使用 Nikon Z5_2 NEF；LibRaw 对该型号返回空颜色矩阵时，使用 RawSpeed 的对应相机校准数据，不使用猜测矩阵。

## 提取引擎与分离方式

0.8候选新增独立“母版准备”页，位于堆栈后。它只读取本插件原导出的32位线性ProPhoto RGB TIFF，在新32位文件中以公共offset/scale映射负值和高光，并报告舍入误差；原母版保持。不会把外来ICC或仅凭位深认定为线性，不修改普通图层上传检查，也不做非线性拉伸或额外显示提亮。准备副本在当前会话仍标记为线性，去星前仍需显影副本。完整的数据约定、来源限制、NaN/Inf边界及保存信息见 [LINEAR_PREPARATION.md](LINEAR_PREPARATION.md)。

- **StarNet（外部 CLI）**：用户单独安装官方完整发行包，步骤见 [README](../README.md#安装-starnet-星点分离引擎)。同一个程序路径根据 EXE 自动识别新版或旧版。新版 StarNet2 2.6.2 使用 float32 FITS 输入/输出，不额外做 16 位中转量化；为兼容中文任务目录，以任务目录为工作目录，传入 ASCII 相对文件名，引擎本身须放在英文路径。旧版 v2.0.2 保留引擎工作目录、16 位 TIFF 与位置参数接口。两者在独立进程中执行。新版自带 DirectML，GPU 不可用时 CPU 回退；选择旧版 EXE 则使用原 CPU 引擎。包内不含引擎、权重或用户图片。步长 256 / 128 / 64；新版最小 512、旧版最小 256，不足尺寸反射补边，输出裁回原尺寸。新版许可原文从 EXE 同目录读取，经用户明确接受后才启用，按内容 SHA-256 记录接受，条款变化时重新确认。图层流程仍要求 `0..1`；不启用新版有高光裁切的 `--linear`。
- **滤色星点**：`S=(I-B)/(1-B)`，用 Photoshop 滤色混合时对应 `I=B+S-B*S`。
- **相加星点**：`S=I-B`，用 Photoshop 线性减淡（添加）混合恢复相加关系。想还原分离前的外观时，混合模式应与分离方式匹配；变亮等其他模式用于外观调整。

网络预测可能局部增亮，背景限定为不超过原图，保证非负星点及默认参数下可逆重混合。提取结果应放大检查星晕、星云细节、亮星和地景；原图层始终保留，便于局部修正。

## 星点加工与背景预览

面板工作流为「堆栈 → 星点分离 → 星点加工」，独立的「星点重混合」页面关闭。用户在星点加工中手动选择星点图层，可选同一源文档中的另一个图层作为预览背景；不自动挑选 `starless` 或 `starmask`。背景只用于观察合成效果，背景处理仍可在 Photoshop 中完成。

选择星点图层后自动在 Photoshop 新标签页打开预览，不需要手动点击预览或画布按钮。预览文档保持源文档的完整像素尺寸和颜色配置，使用独立的背景与星点图层，由 Photoshop 原生混合；可放大到 100% 检查细节。预览标签页打开后，来源选择仍指向原文档，而非预览文档。

混合模式包含正常、变亮、滤色、颜色减淡、线性减淡（添加）、浅色，实际可用项取决于源文档位深和 Photoshop 支持。插件不会为使用不支持的模式自动降低位深。切换背景或混合模式直接修改预览中的图层，不重新运行星点加工算法；切换星点或加工效果则更新预览星点。

本机 Photoshop 2026 的 32 位文档支持正常、变亮、线性减淡（添加）与浅色；滤色、颜色减淡仅在 8/16 位提供。原星点的原生预览不限制浮点范围，但当前加工算法要求星点像素在 `0..1` 内。带负值或超范围高光的 HDR 星点会明确报错，不自动截断或降低位深；请保留原始浮点堆栈，在另一个适合后期加工的副本中处理。

亮度曲线、星点缩小、彗差减少、辉光及饱和度按需展开参数。图层输入与加工结果会缓存，连续拖动时合并待处理的参数请求，以最新设置更新画布；已经过时的计算结果不会覆盖更新的选择。首次读取完整图层、全分辨率辉光及外部 Siril 彗差减少仍可能耗时，取决于图像尺寸、设置及硬件。预览不使用降低分辨率的替代结果，也不承诺所有全尺寸处理都能即时完成。

执行星点加工后，在源文档生成新的 `_processed` 星点图层，并自动设置为用户在预览中选择的混合模式。输出不包含预览背景，不覆盖原星点或背景图层；可在 Photoshop 继续调整图层与混合模式。当前工作流的验证范围见 [验证记录](../VALIDATION.md)。
