# T24：离开加工页停止无用任务

基线21fd65e（`checkpoint/t23-core-processing-cancel-20261022`），分支`codex/core-preview-page-exit-20261022`。仅修基础预览的页面切换，不增加参数、专业能力或新引擎，不恢复网络素材下载及对应验证，不读取或操作Photoshop。

## 根因与行为

原`pageChanged()`在离开加工页时已经尝试取消，但启动组件、读取图层、创建作业均为异步操作。页面离开时尚无作业编号，后续响应回来只检查参数/来源与暂停状态，没有检查当前页面；因此仍可能读取大图、创建任务或接受结果。旧作业的进度和异常也可能覆盖新页面的状态。

在上述异步边界、旧预览释放输入后及真正开始读取的模态回调中重新检查当前页：尚未读取则跳过；读取已经开始则安全完成，不提前释放输入；晚到的作业编号立即请求取消，并等待终态；已完成但过时的结果释放，保留完整输入。离开加工页后的进度与错误不写入其他页的状态。返回加工页仍沿用自动预览，复用有效输入或已有完整缓存，来源和参数选择不变。

本项不强行中断一次PS读取，也不关闭用户预览文档，不更改混合、编码、图像精度、像素算法、应用图层或撤销路径。T23的后台协作取消保持原实现。
