## 修改及边界

只把写回的浮点传输预算由8 MiB调为32 MiB，仍最多512行、仍低于后台64 MiB限制。相同6000宽RGBA的单块由87行变349行，最后一块按剩余行数计算。上传预算、服务器协议、浮点结果缓存、8/16位舍入和32位负值/HDR通道不变；不加入后端量化、裁切、降采样或新设置。每块后的取消检查、释放与调用方事务保持；更大块的瞬时内存和不可分割写入量会增加，需要实际流程继续核对。

三个新增8/16/32位宽图用例在旧实现上仅分块布局预期不符，原像素检查通过；取消对照旧版已经通过，不宣称原实现不能取消。新增检查覆盖每个通道、尾块、原生目标偏移、首块替换和取消后不再拉取下一块。完整回归、无计时插桩的实际面板流程、开发包及完整范围回退将在本阶段按实际结果补充。

私人证据在`artifacts/write-profile-20261023/`：`native-write.json`及`profile-verification.json`。425条断言包含逐带尺寸检查，不代表425项功能；每组全图比较覆盖7200万RGB通道。正式安装未修改，没有恢复网络图像下载或发布Release。
