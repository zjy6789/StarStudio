# T8 堆栈质量与覆盖报告

基线：`checkpoint/t7-native-pending-20261022`。T7原生分层待用户手动验证；本任务不读取Photoshop前台或执行原生测试。已验证main保持0.10.0，当前分支为开发工作，不作为完成的安装版发布。

## 本包数据约定

- 复用堆栈已有的逐帧匹配数、RMS、变换矩阵和覆盖计数，不增加评分模型，不改变配准、插值、校准、累积或异常剔除公式。失败仍明确终止，不默认丢帧。
- 面板主动请求质量报告；旧调用不请求时保持现有输出约定。报告随同名JSON保存，包含完整分辨率覆盖计数的16位灰度PNG（base64，无量化）、显示预览、各覆盖帧数对应的像素数及共同覆盖裁剪建议。
- 覆盖计数来自重采样有效区域，在Sigma剔除前累计，不能称为剔除后有效样本数、信噪比或成像质量评分。基准帧不重采样，覆盖边缘仍沿用现有Lanczos支持范围。
- 裁剪建议只使用全部输入帧共同覆盖的像素，给出轴对齐的全覆盖矩形；约定坐标左/上包含、右/下不包含。没有共同覆盖时不编造矩形。建议只展示，不自动裁剪、遮盖或修改母版；应用裁剪副本是后续独立保存步骤。
- 面板展示基准、逐帧匹配数与像素RMS，基准的RMS=0只是自身对齐。显示质量报告不依赖PS打开结果成功。选择新一组素材时清除旧报告，取消文件选择保留当前组与报告。
- 支持将原始覆盖计数导出为16位PNG；这张图是计数数据，不是照片，不做ICC转换或色调拉伸。显示预览只便于检查边缘，不代替完整图。

## 验收与后续

数值验证包括：已知平移/旋转覆盖与逐像素独立期望、完整PNG往返相等、共同覆盖框内全部满足计数、无公共区域、取消、五种保存格式及T7分层开关、质量报告开关前后主图像素一致、负值/高光和输入哈希保留。报告层另核对PS打开失败后仍可查看、选择取消、旧后台无报告提示与PNG导出二进制，不把mock当原生UI验收。

下一步仍需显式基准更换、失败帧排除/撤回、裁剪副本保存；不把只完成报告显示写成整个质量任务完成。星点尺度、薄云判断、帧间亮度归一化与加权不混入本次数值管线。
