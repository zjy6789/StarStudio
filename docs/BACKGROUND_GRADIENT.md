# T5 背景梯度校正约定

基线：`checkpoint/0.8.0-candidate-20261018`。本阶段独立于星点算法，先完成本任务验收，再进入 T6 受保护拉伸。

## 适用与输出

- 用户明确确认已显影的 RGB / 灰度照片；不推断任意外来照片的阶段，不接收未准备 HDR 母版。
- 从选定图层以 Photoshop Imaging API 的 32 位数据读取，保持原尺寸和对应文档色彩空间。8/16 位照片读取成 32 位时，Photoshop 使用对应的线性配置；模型与输出都在该空间计算，不将整数编码值原样解释成线性光。
- 输入仍要求有限且在 0..1；不放宽旧上传接口。输出允许有限的负值和超过 1 的高光，无 clip、降位深、亮度重映射、降噪或模糊。
- 预览与最终结果都在独立的 32 位副本文档中。使用源文档副本携带 ICC，再以相同位深写入浮点像素；源文档、源层和磁盘文件保持不变。新结果包含原输入与校正结果两个图层，可切换比较。
- 这是对已显影照片的视觉梯度修正，不声称恢复了物理光害或科学颜色校准。暗角优先平场；不提供除法模式。

## 模型与保护

- 固定一阶平面，每颜色通道独立拟合。规则网格中的局部中位数降低点状星点影响，MAD 阈值剔除明显亮区域；以 SciPy `least_squares(loss='soft_l1')` 抑制余下离群样本，不增加依赖或复制外部 GPL 代码。
- Photoshop 选区可作为主体保护，也可明确限定背景取样区。二者分别保存，保护优先。选区仅用于排除/限定拟合，不是输出混合蒙版；主体像素同样减去估计的梯度，弥散结构应保留。
- alpha 小于 0.999 的像素不参与拟合；局部块有效像素不足 90% 时跳过。画布外、透明与低 alpha 边缘不得作为黑背景参与。未以 alpha 表达的低覆盖区域无法自动识别，应由用户保护或限定取样区，不能承诺从不带覆盖信息的照片恢复覆盖率。
- 拟合前检查数量、二维覆盖、秩和条件数；拒绝过少/集中/共线采样，并提示修改选区或跳过。整幅弥散星云的真实背景无法仅由像素判定，用户必须核对取样与模型，不能保证自动建议正确。
- 校正：`result = source - strength * (model - reference)`，reference 为有效样本处拟合背景的逐通道中位数。保留背景基线，不默认压黑或中性化。强度 0 应逐像素还原输入；alpha 始终保留。
- 查看拟合背景时显示完整模型（包含保留的基线），另提供采样位置说明。所有渲染从同一次输入快照和模型重算，不能逐次累减。

## 验收计划

1. 合成彩色平面 + 已知弥散主体：保护主体后恢复平坦背景，主体差值保留；加离群星点仍稳健。
2. 平坦图/零强度、灰度、透明边缘、保护与取样优先级、采样不足与分布退化、非有限值/非法参数、取消和缓存清理。
3. 界面：选择变化使旧模型失效；取消/失败不显示最新；强度、模型/原图比较和最终输出使用同一稳定输入。
4. Photoshop：真实 8/16/32 位及 sRGB/Adobe RGB/Display P3/灰度转换与写回；预览和最终像素、alpha、ICC、源层不变；全尺寸及取消清理。数值或模拟测试不能替代真机证据。
5. 独立提交、GitHub 同步、功能回退点；用独立副本验证整个 T5 提交范围可以撤销。

## 依据

- [Siril 背景提取](https://siril.readthedocs.io/en/stable/processing/background.html)：低阶模型、可编辑采样、减法/除法区别与稳定源重算。
- [SciPy 稳健最小二乘](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)：soft_l1 与尺度参数。
- [Adobe Imaging API](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/imaging)：32 位线性配置、alpha、选区及浮点像素范围。

实现与验收状态将随实际证据补充，不把计划视为已完成。
