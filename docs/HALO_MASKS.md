# T13：蓝紫晕候选蒙版

起点 `checkpoint/t12-files-verified-20261022`（e05ff90），分支 `codex/halo-masks-t13-20261022`。这是调研H项中的色晕局部辅助；去星残留的原图/模型/当前合成比较另作下一包，不混成自动去紫或自动修补。

## 范围与依据

沿用星点加工中的保护蒙版与已确认星点编码，只生成候选覆盖，不改写照片。复用项目已有的[SEP 1.4.1](https://sep.readthedocs.io/en/stable/api/sep.extract.html)紧致源提取，以及SciPy欧氏距离、扩展与柔化。SEP从SExtractor派生，项目已有堆栈使用它；不新增模型、引擎或依赖。Context7只返回同名.NET CSV库，未采用该错误匹配，接口以官方Python文档和当前安装模块为准。

- 黑底、灰底和有符号星点先按已确认编码取得正信号；负差值不当作星晕，透明区不参与检测。灰度无法判断蓝紫，明确拒绝。
- 对派生检测信号做相对峰值归一化，不改变原像素。SEP提取亮而紧致的候选，分块含上下文，避免对整张星云或所有蓝色区域直接处理。
- 候选只在亮星周围指定内外半径的环带：蓝超出红/绿，或红蓝共同超出绿，产生连续覆盖权重。色差以同一正信号峰值为参考，避免把接近零的微弱尾部颜色比放大。它是当前工作RGB下的相对色差，不是光学诊断、CIE色度或真实星色判定。
- 核心保护、外圈、色差门槛及扩展/柔化均可调；扩展和柔化后再次限制环带，保护核心及远处非候选区域。没有可靠候选时停止，避免空选区变成全图操作。
- 用户检查覆盖并确认后，输出可编辑PS选区或完整尺寸32位灰度TIFF。在PS中用色相/饱和度、选择性色彩或蒙版强度局部调整；星云、地景与真实蓝星可能误入候选，必须人工排除。此步不修改图层、不全图压紫、不再次去星、不蒙尘划痕。

自动验收包括带已知位置的白星/蓝紫环/红星/远处蓝云，核心与环外严格零、编码与透明度、空候选拒绝、块边界、参数/来源过期、取消、32位保存及全尺寸性能。PS选区显示、手工排除与调整效果待用户手动验证；按指令不读取PS状态。
