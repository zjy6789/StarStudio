# T20：实拍母版到后期副本的文件验证

起点 `checkpoint/t19-code-verified-20261022`（ca82743）。本阶段只补原调研第8节的实拍文件证据，不增加功能、修改算法或操作Photoshop；软件版本仍0.23.0。使用此前已获准的本地实拍堆栈产物，私人照片与输出不进公开仓库。

## 验证范围

1. 一组3张真实RAW亮场、3张暗场和3张偏置生成的6064×4040线性ProPhoto RGB float32母版；复用已核对的堆栈文件，不重复去星或模拟原生操作。
2. 实际母版含负值和超1高光。执行现有T4检查/范围准备，逐块独立复算并检查来源哈希、记录和存储误差；不删除异常像素、忽略极值或裁切数据来使检查通过。
3. 对原样T4副本运行T6自动建议、零强度与实际提亮，核对源不变、零强度逐位一致、共同RGB增益、端点和文件元数据。该测试直接注入已知线性确认，不代表用户点击过界面。
4. 在已提亮副本上比较默认取样与示例区域保护的T5平面校正，保留完整浮点输出。示例保护只排除取样，不把它说成输出不变区或自动银河/地景识别。
5. 显示比较采用相同ProPhoto→sRGB转换和显示曲线，无单格自动增强；8位预览允许显示裁切，32位母版/结果不因此裁切。没有真实无光害真值，不能把平面变化或更平坦背景当作科学质量改善。

实拍材料仅证明本组星野文件链路；带山脊/灯光、满幅发射星云/暗云、星系光晕及人工新手观察仍需各自证据。若发现范围准备改变颜色比例或细节精度，明确量化代价，不改为未声明的去噪、模糊、黑点裁切或新去星策略。
