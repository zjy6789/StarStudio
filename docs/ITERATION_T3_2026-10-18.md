# T3：星点参数与比较

基线为已推送到 GitHub 的 `616c20d`，标签 `checkpoint/0.7.0-candidate-20261018`；开始时工作区干净。本轮在 `codex/star-controls-t3-20261018` 分支实现调研报告的 T3，保持原算法、颜色/位深约定及完整分辨率原生预览。T4–T7 留待各自任务，不改全局像素范围检查。

## 用户行为

- 星点亮度、缩星、颜色、拉长星点修整各先显示一个主要控制；辉光先显示强度与半径。高级参数折叠，仍使用原来的参数数值与范围；展开不启用效果。
- “拉长星点修整”继续调用 Siril 做圆星重建，默认关闭，不称为光学恢复。
- “自然控星”只启用缩星：强度0.25、半径1原图像素、暗星阈值0.01、高光保护起点0.8。“柔和亮星”只启用辉光：强度0.6、半径12原图像素，其余保持原默认值。两者明确替换当前设置，并显示启用项及实际半径；重置关闭全部效果，恢复原生原合成。
- 半径只是可修改的起点，不能以照片总像素数推断星点大小。本轮不引入未经验证的自动尺度识别；需要在100%视图按星点实际尺寸调整。它不代表任意分辨率或实拍题材的最佳参数。
- 选择背景后，“查看原合成”在同一预览文档、同一背景和混合模式下绕过星点加工；不选背景时为“查看原星点”。它只影响比较，执行仍使用当前加工参数。没有复制新的预览标签或切换缩放设置。
- 预览标签含源文档名；面板根据实际写入的结果说明当前是否为最新参数、原合成或上次结果。过时的任务结束后不能将旧结果标成最新；失败不自动无休止重试。

## 验证与边界

自动与原生检查完成后记录在 [VALIDATION.md](../VALIDATION.md)。初始半径的合成测试覆盖96×96、256×192、768×512画布和三个星点尺度，检查暗星保护、源/alpha不变与填充画布后的局部一致性；不能代替24MP实拍质量评价。

本轮不改变32位HDR输入边界、不增加背景校正或拉伸算法，不承诺全部参数实时完成。现有外来图层手动选择与本会话编码关联保持。

## 版本与回退

T3生产代码、行为测试与本记录作为一个功能提交，版本号与发行说明另行提交。需要回到T3之前，可在单独工作树查看 `checkpoint/0.7.0-candidate-20261018`，不会改动当前目录。

撤销T3时在工作区已保存且干净的分支执行 `git revert <T3功能提交>`，保留T1/T2。此操作保留历史，不使用强制重置。回退源码后需重新部署相应面板；它不撤销用户的PSD编辑，也不替代照片备份。
