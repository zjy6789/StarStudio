# T23：过期星点加工及时停止

基线155f59e（`checkpoint/t22-core-preview-selection-20261022`），分支`codex/core-processing-cancel-20261022`。本项只改善星点加工的基本响应，不增加控件或专业能力，不下载网络图片，不开展已跳过的素材验证，不读取或操作Photoshop。

## 根因与范围

原面板已发送取消，但后台`processStars`只在整次加工前后检查。复现用例中，收到取消后半径12与36的两次辉光模糊仍然执行，旧任务一直占用单个工作线程；Siril星形修整也要等待进程正常结束或600秒超时。最后丢弃结果不能消除这段等待。

现将同一取消信号传入加工阶段、每128行/列滤波批次及Siril等待循环。每批都覆盖滤波轴全长，不截断邻域；小半径保持SciPy逐轴高斯，较大半径保持原有限核、对称边界和FFT计算。未完成的辉光或星形结果不写入缓存，完整缓存仍可复用；输入与alpha不改写。

Siril使用双管道`communicate(timeout)`读取，约0.1秒检查一次取消并保留600秒期限。超时或取消后只终止本次启动的子进程，再读尽管道并回收；不查找或结束其他Siril、PS或用户进程。正在运行的单个滤波批次/其他数组操作会先结束，取消不是实时硬中断；未承诺固定毫秒响应，也没有改变StarNet分离的取消契约。

实现依据：[Python子进程超时与回收](https://docs.python.org/3.12/library/subprocess.html#subprocess.Popen.communicate)、[SciPy逐轴高斯接口](https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.gaussian_filter1d.html)，并核对项目环境中`gaussian_filter`的实际逐轴实现。没有新增算法、依赖或精度转换。
