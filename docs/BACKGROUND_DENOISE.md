# T11：背景降噪接入与数据约定

起点为已推送且回退验证通过的 `checkpoint/t10-files-verified-20261022`（8c1ba98），独立分支 `codex/background-denoise-t11-20261022`。按用户要求，不读取PS状态、不执行原生验证；此前原生项仍待用户手动验证。

## 三条路径的核对

| 路径 | 已查证的收益与成本 | 本轮决定 |
| --- | --- | --- |
| PS现有工具 / Camera Raw | [Adobe降噪说明](https://helpx.adobe.com/camera-raw/using/enhance.html)列出RAW/部分线性DNG等输入，不能把普通TIFF/PSD图层默认当作AI Denoise支持来源；[UXP Layer](https://developer.adobe.com/photoshop/uxp/2022/ps_reference/classes/layer/)的Despeckle/Median排除RGB/灰度32位。用户已要求停止PS操作，因此没有做原生效果/速度比较 | 保留用户自选的PS流程，不为调用滤镜降低当前32位图像位深，不虚构真机效果 |
| 内建浮点NLM | 复用scikit-image 0.26.0非局部均值、PyWavelets 1.10.0与现有浮点副本。无额外模型或引擎，支持颜色、灰度；有已知真值的可复现试验、范围和分块验证 | 本轮只把这一条方案加入UI，基础只放强度与细节保护；默认仅色噪，亮度降噪在高级选项中显式选择 |
| GraXpert 3.0.2 | 已核对[官方CLI](https://github.com/Steffenhir/GraXpert/tree/3.0.2)、[文件加载源码](https://github.com/Steffenhir/GraXpert/blob/3.0.2/graxpert/astroimage.py)、[推理源码](https://github.com/Steffenhir/GraXpert/blob/3.0.2/graxpert/denoising.py)。未修改的官方加载方法在合成TIFF探针中将[-0.125,2]映射成[0,1]，768个通道全部变化；推理还涉及按通道MAD归一化与阈值。程序/模型、GPU与调用错误也增加部署成本 | 未经专门范围适配和模型验收不能直接接入当前浮点链路。本轮不捆绑、不调用其神经模型；不据加载探针宣称内建画质优于GraXpert |

GraXpert探针只执行固定3.0.2源码的原始 `set_from_file` 方法，未执行CLI、GPU或模型；源码SHA256为 `809772a407beaca2514d5ea85f563997dde4a554cf3fdb24a3abec0c19ac719f`。这是输入契约证据，不是外部引擎完整效果测试。没有复制其GPL代码到插件运行模块。

候选NLM在256×384、已知高斯噪声σ=0.006的合成图上，估计σ=0.005869；仅色噪模式的色差RMSE从0.005669降至0.000676，保留原工作RGB亮度（float64最大差1.39e-17）；联合模式RGB RMSE从0.005999降至0.000711。单次算子0.056秒。整图与带8像素上下文的64块最大差4.38e-11。以上为未混合的候选算子，不是默认强度、真实照片信噪比、PS延迟或细节无损承诺。

## 首版处理契约

- 使用现有背景页手选图层，确认已显影；本内建路径仅在该工作RGB/灰度阶段验证，不代表所有降噪都必须在拉伸后进行。未准备线性母版不自动带入。
- 默认仅处理用户显式读取的背景选区。也可明确选择整层无星背景；无星不等于无地景，不能悄悄把整幅普通照片当背景。有星图可先使用保护蒙版的星点外选区。原选区是稳定快照，不在参数重算时重读。
- 从作用区域内连续背景小块用现有 `estimate_sigma` 的db2小波估计高频噪声，优先较暗块。另复用既有SciPy稳健平面拟合与Astropy MAD统计，测量去除局部平面后的残差；两者差距大可能是相关噪声，也可能是真实结构。默认保留低频变化；仅在用户确认参考块为平稳背景后，显式开启相关色噪处理。更换来源、范围或重新读取会清除该确认。找不到连续可靠取样时拒绝；不虚构最小噪声强行柔化，估计为零时原样输出。估计不是传感器精确测噪。
- 使用scikit-image公开NLM：float64中间计算、`preserve_range=True`、显式通道轴，不转换成8/16位，不整体归一化或裁切。固定patch5、搜索5；细节保护控制h，保护越高平均越弱，不声称识别或恢复微弱真实结构。
- 分块保留8像素上下文，用户目标范围外不混合；透明边界缺少有效邻域时保守保留原像素，不填补照片。快速积分距离存在数值条件，极端跨度/噪声比将明确拒绝，不以裁切掩盖。
- RGB默认仅色噪：对滤波修正投影，保留原工作RGB加权亮度；不是CIE物理亮度或任意ICC的测光保证。高级联合模式会改变亮度，也可能削弱暗弱细节；灰度显式使用亮度模式。强度0、区域外、透明区保持原位模式，alpha始终保留。
- 专用 `/denoise-sources` 保留有限float32输入及[0,1]alpha，与旧去星入口隔离。NLM修正缓存使用内部float64存储，不经旧图像RPC输出；调整强度只重混合，不重复滤波，改变细节保护重算缓存。
- 预览/原输入在相同PS显示条件比较，完整尺寸输出到独立32位副本，复用已定义的原输入+剪贴效果层结构，保留ICC和不透明度调节。必须检查当前结果后确认应用；原用户文档不变。

依据：[scikit-image NLM与噪声估计](https://scikit-image.org/docs/stable/api/skimage.restoration.html)、[PyWavelets](https://github.com/PyWavelets/pywt)。只增加这一种内建算法，不把三套引擎放进首页。PS显示、选区、剪贴透明度与撤销待用户手动验证。
